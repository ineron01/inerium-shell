# Inerium Camera — Инструкция по настройке смартфона

`inerium-camera` позволяет использовать Android-смартфон (основную или фронтальную камеру в формате 16:9 или 9:16) либо встроенную веб-камеру ноутбука в качестве постоянной виртуальной веб-камеры Linux (`/dev/video0`, имя `PhoneWebcam`).

Работает через Android Debug Bridge (`adb`) и `scrcpy` по кабелю USB или через Wi-Fi. **Установка сторонних APK на телефон не требуется.**

---

## 1. Подготовка смартфона (выполняется один раз)

1. Откройте **Настройки** на Android-смартфоне.
2. Перейдите в раздел **«О телефоне»** (или «Сведения о ПО»).
3. Быстро нажмите 7 раз на пункт **«Номер сборки»** (появится сообщение *«Вы стали разработчиком!»*).
4. Вернитесь в Настройки -> **«Система»** (или «Дополнительные настройки») -> **«Для разработчиков»**.
5. Включите пункт **«Отладка по USB»**.
   *(Для пользователей Xiaomi / MIUI / HyperOS: дополнительно включите «Установка через USB» и «Отладка по USB (Настройки безопасности)»).*

---

## 2. Первое подключение по USB

1. Подключите смартфон к ПК USB-кабелем.
2. На экране телефона появится всплывающее окно: **«Разрешить отладку по USB?»**.
3. Поставьте галочку **«Всегда разрешать с этого компьютера»** и нажмите **«Разрешить»**.
4. Запустите `inerium-camera` (или ярлык в меню **Inerium Camera**):
   - Устройство появится в списке доступных камер.
   - Нажмите кнопку **«Старт»** для запуска трансляции.

---

## 3. Беспроводной режим (Wi-Fi / Точка доступа)

Телефон не обязательно держать на проводе:

1. Убедитесь, что телефон и ПК находятся в одной Wi-Fi сети (или телефон подключен к раздаче с ноутбука, например через `inerium-hotspot`).
2. При подключенном USB-кабеле нажмите в окне `inerium-camera` кнопку **«Включить Wi-Fi режим»** (или выполните `adb tcpip 5555` в терминале).
3. Отключите провод.
4. Приложение автоматически найдет смартфон в локальной сети и подключит видеопоток по Wi-Fi.

---

## 4. Использование в программах

В любом приложении выберите камеру **PhoneWebcam** (`/dev/video0`):
- **Discord** -> Настройки -> Голос и видео -> Камера
- **Telegram** -> Настройки -> Звонки -> Камера
- **Браузеры** (Chrome, Firefox, Chromium) для Google Meet, Яндекс.Телемост, Zoom
- **OBS Studio** -> Устройство захвата видео (V4L2) -> `/dev/video0`

### Возможности и управление
- Горячее переключение между **основной камерой**, **фронталкой** и **камерой ноутбука** прямо во время активного созвона без перезапуска приложения.
- Переключение между альбомным (**16:9**) и портретным (**9:16**) режимами (с автоматическими черными полосами по бокам, без искажения пропорций).
- Включение фонарика (вспышки) смартфона из интерфейса.
- При выключении стрима виртуальная камера `/dev/video0` выдает студийный черный экран, поэтому звонок в Discord/Meet не вылетает с ошибкой.
