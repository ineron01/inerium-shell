# 🚀 Inerium Desktop — Руководство по горячим клавишам и управлению

[ [English](keybindings.md) | Русский ]

Добро пожаловать в **Inerium Desktop**! Эта система построена вокруг композитора **Hyprland** (Lua API), статусной панели **Waybar** и фирменного набора утилит **Inerium** на Rust.

Главный принцип управления — **клавиатурная эргономика и автоматический тайлинг**: окна организуются аккуратно без нагромождения друг на друга, а ключевые действия выполняются мгновенно комбинациями клавиш. При этом система полностью поддерживает привычное управление мышью и плавные мультитач-жесты тачпада ноутбука.

> [!TIP]
> Основная клавиша-модификатор (**`Super`**) — это клавиша **`Windows`** (или **`Cmd`** на клавиатурах Apple).

| Действие | Комбинация | Описание |

## 🪟 1. Управление окнами (Тайлинг)

Окна автоматически размещаются эргономичной плиткой (тайлинг). Вы можете менять их геометрию, переводить в плавающий режим или разворачивать на полный экран.

| Комбинация | Действие |
| :--- | :--- |
| `Super + Q` | **Закрыть** активное окно |
| `Super + Shift + Q` | **Принудительно закрыть** (SIGKILL) зависшее окно |
| `Super + Escape` | **Режим «Убийцы окон»** — курсор превращается в прицел; клик по любому окну закрывает его |
| `Super + F` | **Эксклюзивный полноэкранный режим** (Fullscreen, скрывает панель Waybar) |
| `Super + D` | **Максимизация** (развернуть на весь экран, сохраняя панель Waybar) |
| `Super + Alt + Пробел` | **Плавающий режим** (Toggle Float) — открепить окно от сетки тайлинга |
| `Super + J` | **Сменить деление тайлинга** (Toggle Split) — горизонтальный / вертикальный сплит |
| `Super + ← / → / ↑ / ↓` | **Смена фокуса** — перейти к соседнему окну в выбранном направлении |
| `Alt + Tab` | **Циклический фокус** — переход к следующему окну на текущем столе |
| `Super + Shift + ← / → / ↑ / ↓` | **Переместить окно** — поменять положение окна в сетке тайлинга |
| `Super + Shift + Колесико мыши вверх / вниз` | **Переместить окно на монитор** — отправить окно на соседний монитор (-1 / +1) |
| `Super + Ctrl + Shift + ← / →` | **Переместить окно на стол монитора** — отправить на следующий / предыдущий стол текущего дисплея |
| `Super + Ctrl + Shift + Колесико вверх / вниз` | **Переместить окно на стол монитора** колесиком мыши |

## 🖥️ 2. Рабочие столы (Воркспейсы) и мониторы

Рабочее пространство разделено на виртуальные столы. При подключении внешнего дисплея столы автоматически распределяются по мониторам (например, 1–3 на ноутбуке, 4–6 на внешнем мониторе).

| Комбинация | Действие |
| :--- | :--- |
| `Super + 1..6` | **Перейти** на рабочий стол 1–6 |
| `Super + Shift + 1..6` | **Перенести окно** на стол 1–6 и перейти за ним |
| `Super + Alt + 1..6` | **Тихий перенос** — отправить окно на стол 1–6 без переключения активного стола |
| `Super + Ctrl + ← / →` | Переключить стол на текущем мониторе (предыдущий / следующий) |
| `Super + Ctrl + ↓` | Перейти на **первый свободный пустой** воркспейс на текущем мониторе |
| `Super + Ctrl + 1..3` | Сфокусировать физический монитор 1, 2 или 3 |
| `Super + S` | **Scratchpad (Карман)** — скрыть / показать специальный рабочий стол |
| `Super + Shift + S` | **Отправить в Scratchpad** — убрать текущее активное окно в фоновый карман |

## 🖱️ 3. Мышь и экранная лупа (Zoom)

| Комбинация / Действие | Результат |
| :--- | :--- |
| `Super + Зажать ЛКМ` | **Перетаскивание окна** мышью (работает и для тайлинговых окон) |
| `Super + Зажать ПКМ` | **Интерактивное изменение размера окна** мышью |
| `Super + Колесико мыши` | Быстрое перелистывание рабочих столов текущего дисплея |
| `Super + Ctrl + Колесико мыши` | Листать рабочие столы монитора |
| `Super + Plus (+)` / `Minus (-)` | **Экранная лупа (Zoom)** — плавное аппаратное приближение от 1.0x до 3.0x (шаг 0.3) |
| `Super + Numpad [+]` / `[-]` | Масштабирование экрана с цифрового блока клавиатуры |

## 🖐️ 4. Жесты тачпада (Touchpad Gestures)

Для владельцев ноутбуков поддерживаются нативные плавные мультитач-жесты:

- **Свайп 4 пальцами влево / вправо** — быстрое переключение между рабочими столами.
- **Свайп 3 пальцами вниз** — закрыть активное окно (`close`).
- **Свайп 3 пальцами вверх** — развернуть окно на весь экран (`fullscreen`).
- **Свайп 3 пальцами влево** — переключить окно в плавающий / тайлинговый режим (`float`).

## 🎵 5. Мультимедиа и системные клавиши

Регулировка громкости и яркости отображается через плавный OSD-индикатор (**SwayOSD**):

- **Громкость:** Клавиши `Fn + Volume Up / Down` (или выделенные мультимедийные клавиши звука).
- **Mute звука:** Клавиша `Mute` (или `Fn + Mute`).
- **Mute микрофона:** Клавиша `Mic Mute` (индикатор на клавиатуре синхронизирован).
- **Яркость:** Клавиши `Fn + Brightness Up / Down`.
- **Медиаплеер:** Клавиши `Play / Pause`, `Next Track`, `Previous Track` (управляют плеером браузера, Spotify, MPV и др.).

## 💡 6. Секреты и возможности панели Waybar

Верхняя статусная панель Inerium Waybar — полностью интерактивная. Большинство модулей реагируют на клики ЛКМ, ПКМ и колесико мыши:

- **Иконка ОС (слева):**
  - *ЛКМ:* Открыть меню приложений (Rofi).
  - *ПКМ:* Открыть менеджер истории буфера обмена (`inerium-clipboard`).
- **Виджет рабочих столов:**
  - *ЛКМ:* Перейти на выбранный рабочий стол.
  - *Колесико мыши:* Переключение на следующий / предыдущий стол текущего монитора.
- **Виджет мониторинга железа (CPU / RAM / Температура):**
  - *ЛКМ:* Переключить отображение CPU ↔ RAM.
  - *ПКМ:* Запустить подробный интерактивный системный монитор `btop`.
- **Виджет медиаплеера (MPRIS):**
  - *ЛКМ:* Открыть карточку трека с кнопками управления (`inerium-popup media`).
  - *ПКМ:* Поставить трек на паузу / снять с паузы.
  - *Колесико мыши:* Переключение на следующий / предыдущий трек.
- **Пустое пространство панели (справа и слева от часов):**
  - *Клик ЛКМ / ПКМ:* Мгновенно открыть **Центр управления** (`inerium-popup control`).
- **Часы и календарь (по центру):**
  - *ЛКМ:* Переключить краткий (`HH:MM`) или полный (`День недели, ДД Мес ЧЧ:ММ`) формат даты.
  - *ПКМ:* Сбросить выбранный месяц календаря на текущий.
  - *Колесико мыши:* Листать месяцы календаря вперед и назад.
- **Индикатор раскладки:**
  - *ЛКМ:* Переключить язык ввода (US ↔ RU).
- **Звук:**
  - *ЛКМ:* Быстрое меню вывода звука и микрофонов (`inerium-popup audio`).
  - *ПКМ:* Включить / выключить звук (Mute).
  - *СКМ (Колесико):* Открыть расширенный микшер `pavucontrol`.
  - *Прокрутка колесиком:* Точная регулировка громкости с шагом 2% через SwayOSD.
- **Сеть / Wi-Fi:**
  - *ЛКМ:* Меню доступных Wi-Fi сетей (`inerium-popup network`).
  - *ПКМ:* Быстрое включение / выключение адаптера Wi-Fi (`inerium-toggle-network`).
  - *СКМ:* Открыть редактор сетевых подключений (`nm-connection-editor`).
- **Точка доступа Wi-Fi (Hotspot):**
  - *ЛКМ:* Быстрое включение / выключение раздачи интернета (`inerium-hotspot toggle`).
- **Bluetooth:**
  - *ЛКМ:* Список сохраненных Bluetooth-устройств для подключения в 1 клик (`inerium-popup bluetooth`).
  - *ПКМ:* Включение / выключение адаптера Bluetooth (`inerium-toggle-bluetooth`).
  - *СКМ:* Менеджер устройств `blueman-manager`.
- **Батарея:**
  - *ЛКМ:* Переключить отображение (процент заряда % ↔ расчетное оставшееся время работы).
- **Колокольчик (DND):**
  - *ЛКМ / ПКМ:* Режим «Не беспокоить» (Do Not Disturb) — глушит всплывающие уведомления.
- **Кнопка Центра управления ():**
  - *ЛКМ / ПКМ:* Открыть панель быстрых настроек Inerium Control Center (`inerium-popup control`).
- **Кнопка питания (⏻):**
  - *ЛКМ:* Меню выключения, сна, перезагрузки, блокировки и выхода (`inerium-popup power`).
