Fast, cohesive, and resilient desktop environment powered by Hyprland Lua, Waybar, and 21 native Rust micro-utilities.

💡 Auto-detects GPU, CPU cooling, and battery; launches interactive TUI selection; prebuilt binaries ensure instant install without heavy local compilation.

Core Architecture & Capabilities

⚡

21 Native Rust Utilities

Zero script overhead. Native battery, temperature, network, layout, and control center daemons running under 2ms latency.

🎨

SSoT Theme Engine

Kanagawa Dragon and Inerium Light out-of-the-box, plus a pool of 8 community palettes with instant GTK and Waybar refresh.

🖥️

Hyprland Lua Tiling

Modern declarative configuration cleanly separated from hardware quirks, eliminating fragmented local overlay files.

📊

Waybar Telemetry

Comprehensive Waybar panel with hardware sensor monitoring, layout switcher, and responsive Control Center popups.

🛠️

First-Login Setup Wizard

GTK4 onboarding wizard with graphical display resolution calibration, theme gallery, and embedded sign-in terminals.

📦

Atomic Config Deploy

Configs deployed directly into ~/.config/ as real files with manifest tracking, .bak backups, and clean uninstaller.
